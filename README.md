## 📌 Technical Overview
**TimeFighter** challenges players to score as many taps as possible within a dynamic time limit. It demonstrates precise Android timer concurrency, button tap debouncing, scale and fade animations, and state preservation across device rotations.

### 💼 Technical Highlights
- **CountDownTimer Concurrency**: Accurate countdown loop with real-time UI synchronization and game-over triggers.
- **Dynamic View Animations**: Scale animations (`AnimationUtils.loadAnimation`) providing physical feedback on each tap.
- **Activity Lifecycle State Retention**: Saves and restores score and remaining time across configuration changes (portrait/landscape rotation).
